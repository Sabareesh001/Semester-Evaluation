# 📦 Semester Evaluation Portal

> A Centralized Application to manage the whole semester paper evaluation for colleges.<br>
<ol>
  <li>This Includes Splitting Papers</li> 
<li>Assigning/Replacing Staffs</li> 
  <li>Assigning/Replacing Examiners</li> 
<li>Generating Reports</li> 
</ol>
